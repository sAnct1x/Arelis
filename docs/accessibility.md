# Accessibility

Screen readers and Windows UI Automation can reach the message box in
the chat window, and the Allow and Deny buttons on a confirmation
card. The message box is named Message. The buttons are named Allow
and Deny; activating them allows or denies that step.

While the Overseer is open, the chat composer and transcript are hidden
and disabled, so a screen reader or UI Automation client sees them as
hidden or disabled and cannot send from them. When the Overseer closes,
chat comes back for the current theme: a reply that arrived while it was
open is visible, and in Filament the transcript stays on the chat tile.

## Settings, memory

Press **Ctrl+,** to open Settings from the main window or the chat window,
in every theme. Focus starts on Close; Tab twice reaches the Settings tabs,
and the arrow keys pick a tab. From memory, Tab twice reaches the list.
Outside Filament the title bar's settings button is also named Settings.
In Settings, the tab strip is named Settings tabs and the memory tab is
named memory.

On the memory tab:

- **Filter facts**: the filter box.
- **Active facts**: the list. Each row is named by the fact's own words,
  without the dates. Selecting a row selects that fact.
- **Edit fact** and **Forget fact**: the buttons. Enter in the list edits
  the selected fact and Delete forgets the selected facts.
- The edit box is named **Fact text**, with **Save** and **Cancel** buttons.
  Tab moves from the box to the buttons.
- **Close** closes Settings.
