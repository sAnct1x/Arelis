# Quit

Closing the window hides Arelis in the tray when the tray is available.
The window goes away right away. Inbound texts and Hey Arelis keep
working.

Quit from the tray stops Arelis completely. The window disappears at
once. Saving memory and stopping listeners happens after the glass is
gone, so the UI does not freeze on close.

Use Quit when you want her fully gone. Closing the window is not Quit.
