# Arelis v0.3.3

Arelis is a locally hosted personal AI assistant, with a focus on science and research. This release changes the chat model, removes Rooms, and brings Sentinel into the repo.

- The chat model is now Qwen3.6 35B-A3B, run by llama.cpp. On first run Arelis offers to download it again, and the download percent stays put if you press Stop. A smaller Q3 build is offered for cards with less memory. ([#402](https://github.com/sAnct1x/Arelis/issues/402), [#403](https://github.com/sAnct1x/Arelis/issues/403), [#413](https://github.com/sAnct1x/Arelis/issues/413), [#423](https://github.com/sAnct1x/Arelis/issues/423))
- Pictures you attach in chat now go to the model as pictures, so it can see them. ([#407](https://github.com/sAnct1x/Arelis/issues/407), [#421](https://github.com/sAnct1x/Arelis/issues/421))
- Rooms and the Workspace dock are gone. Reality stays as its own view. ([#431](https://github.com/sAnct1x/Arelis/issues/431))
- Sentinel now lives in this repo. When you run Arelis from a source checkout, it starts Sentinel in the background and stops it when you quit. If Sentinel fails to start, Arelis keeps running. The installer does not include Sentinel yet. Every Sentinel control route needs the session token, a stop stays stopped after a restart, and outward actions need sign-off. ([#434](https://github.com/sAnct1x/Arelis/issues/434), [#435](https://github.com/sAnct1x/Arelis/issues/435), [#436](https://github.com/sAnct1x/Arelis/issues/436), [#439](https://github.com/sAnct1x/Arelis/issues/439), [#441](https://github.com/sAnct1x/Arelis/issues/441))
- Weather is spoken as a plain sentence. ([#397](https://github.com/sAnct1x/Arelis/issues/397))
- Fixes: closing the window no longer freezes for a few seconds, Quit from the tray closes the Arelis browser, a withdrawn reply no longer repeats sentences you already heard,, a dead Google sign-in can be redone, and quitting during first-run setup no longer crashes the download. ([#390](https://github.com/sAnct1x/Arelis/issues/390), [#394](https://github.com/sAnct1x/Arelis/issues/394), [#395](https://github.com/sAnct1x/Arelis/issues/395), [#396](https://github.com/sAnct1x/Arelis/issues/396), [#411](https://github.com/sAnct1x/Arelis/issues/411))
- More fixes: saying no to a tool gets a plain reply, a declined document save just ends, asking for a summary of an attached PDF reads it instead of starting a new document, chat scroll no longer sits one line short, tall diagrams fit the preview, the avatar no longer drops, and a lone city name in chat flies the globe there. ([#410](https://github.com/sAnct1x/Arelis/issues/410), [#416](https://github.com/sAnct1x/Arelis/issues/416), [#420](https://github.com/sAnct1x/Arelis/issues/420), [#425](https://github.com/sAnct1x/Arelis/issues/425), [#426](https://github.com/sAnct1x/Arelis/issues/426), [#428](https://github.com/sAnct1x/Arelis/issues/428), [#429](https://github.com/sAnct1x/Arelis/issues/429))
- Security updates for pillow, pypdf, and certifi. ([#400](https://github.com/sAnct1x/Arelis/issues/400))

Installer still isn't signed, so Windows will warn you. Hit More info, then Run anyway.
