# Arelis v0.3.2.1

Two picture fixes.

- Removing a background now opens the cutout from the data folder in the Workspace pane. Before, Workspace was pointed at the wrong path and could not load the file. The pane shows a short path, with no username in it. Chat says "Image ready: open in Workspace". The picture is in the Workspace pane, not in the chat. ([#307](https://github.com/sAnct1x/Arelis/issues/307))
- A finished diagram now fires the image-ready event, so it opens in the Workspace pane. Chat says "Image ready: open in Workspace". The picture is in the Workspace pane, not in the chat. ([#308](https://github.com/sAnct1x/Arelis/issues/308))

Installer still isn't signed, so Windows will warn you. Hit More info, then Run anyway.
