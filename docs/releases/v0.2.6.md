# Arelis v0.2.6

What the next installer should ship. The GitHub file is still
**0.2.5**. Living notes for this checkout are in
[whats-new.md](../whats-new.md).

0.2.5 cut the prompt to a telegraph so every turn was not a 22k
prefill. That ship did not prove conversation: a deep research ask
could stay on 8 fast rounds, empty chat after a scrape could paste
the page, and a granted folder did not open the files inside it.

This notes the fixes. It is not a new setup `.exe` until one is
built and published.

---

## Turns

"Deeply research" is a 32-round ask even when the composer chip
still says fast. Bare "look this up" stays at 8.

Empty chat after a long scrape or search asks her to write in her
own words. A short fact (a price, an agenda create) still ships
from the tool. Last resort is a lede, not the article.

`research_report` retries a shorter query (and drops a year filter)
when the first search is empty. Findings drop journal chrome and
keep the abstract. She is told not to invent material tables or
close with a menu of code she could write.

Highlight-and-drag in the composer extends the selection. It does
not start a Move drag that deletes the draft.

## Workspace

A folder you Allow for this session includes the files inside it.
If a path is outside roots, she stops. She does not list
`Documents` or `C:\Users`. Add the folder in Settings → roots, or
Allow the path you named.

Launch that resumes a room opens a new empty chat in that room.
Last night's thread stays in History.

The prefix cache, skinny schemas, Reality as a permanent room

and the Earth zone stay source-checkout. The installer is still
