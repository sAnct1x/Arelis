# Arelis v0.2.5

What the 0.2.5 installer ships. Living notes for a source checkout are
in [whats-new.md](../whats-new.md).

Every turn still lists every tool, so Ollama can reuse the prefix —
but the essays are gone. The persona is unchanged. The policy is a
telegraph. Schema descriptions are one line. Prefill dropped from
about 22k tokens to about 5,500.

---

## Turns

Persona (~900 tokens) is the same voice. Skill-card essays stay in
`skills.py` for humans and for turn classification; they are not
pasted into the prompt. Ollama sees `compact_tool_policy()` plus
skinny schemas (names, enums, required — no param essays).

The full 39-tool array still rides every turn. Subsetting mid-turn
was measured slower: it busts the prefix cache.

Launch still pins the model and seeds that prefix. The window says
**loading the model…** until the seed is done.

## Glass and browser

Her Chrome is a normal window on one desk, not the 1 / 2 / 3 span.
Drive **Stop** / **pause** / **go** still work from the strip or
out loud. Housekeep still prunes Cache / GPU only.

## Reality

The room (slash id `physics`) cannot be forgotten. Installed copies
get the room: chat, CAS, Horizons. The true-scale plate, hands, and
the Earth zone need a source checkout and the astro extra.

## Not in this installer

- The 3D Reality plate and the Earth zone
- Code signing (SmartScreen will still warn)
- Bundling Ollama inside the setup `.exe`
