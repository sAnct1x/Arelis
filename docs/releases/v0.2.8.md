# Arelis v0.2.8

What you get if you install this one. Checkout notes stay in
[whats-new.md](../whats-new.md).

0.2.7 finished the house. This one is the daily-driver pass: scanned
PDFs that used to read as nothing, the tools that were missing, the
Allow holes, and a model picker after setup.

---

## She does the thing you asked

`/tools` lists every tool by name and one line. The idle TOOLS chip
is the same list — a first-run profile actually paints it now.
`remind me in 20 minutes` is an in-process timer,
not a Windows scheduled job. `notes` lists and searches the pages
`keep this:` already writes. `recall action=docs` searches indexed
files. `transcribe` uses the warm voice engine and will not load
Whisper mid-turn. `workspace patch` applies a unified diff.
`sql` is read-only SELECT. `agenda free` answers when Thursday is
open. `pdf` merges, splits, and rotates.

A turn that hangs unlocks after 90s. Export conversation sits next
to copy · again. History search hits message bodies. Workspace
Ctrl+Z reaches the editor.

## Scanned PDFs

A handwritten or scanned PDF with no embedded JPEGs is rendered
with pypdfium2. If that library is missing, the extract fails out
loud (`fail:rasterizer`) instead of returning empty. The installer
carries the pin. Vision still walks the page images one at a time;
the extract does not look at them itself.

## Allow

`research_report` writes a file and shows the writes card.
The webcam answers to the same vision toggle as looking at a still.
A typed file outside the workspace is still a session grant, not a
tool the model can call.

## Settings

Chat / Research / Vision tags can be picked after the setup wizard.
The next reply uses the new tag. Restart still pins from boot.

## Phone companion

The radio starts on cellular, not only Wi-Fi. A paired phone keeps
the Allow poll while the app is backgrounded. A quiet week no longer
kills the bridge: inbound rediscovers the PC, WifiWatcher lives on
the radio service, and queued texts last 30 days. Doze can still
stop the Google Messages listener — Battery Unrestricted. Sideload
this APK; the one already on the phone still has the old path.

## Same as 0.2.7

Still not signed. Ollama and the voice weights are still not in
the `.exe`. Earth / Reality 3D stay on a source checkout. There is
no general shell — `run_script` is the project-program path.
