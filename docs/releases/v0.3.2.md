# Arelis v0.3.2

Mostly fixes, plus a couple of new picture tools.

- Weather answers work properly now
- A plot chart is drawn with the reply
- A diagram is saved to a file. The picture does not show in chat. Workspace does not open it yet ([#305](https://github.com/sAnct1x/Arelis/issues/305))
- A background cutout is saved to a file. The picture does not show in chat. Workspace can fail to open that picture ([#304](https://github.com/sAnct1x/Arelis/issues/304))
- Longer jobs don't get cut off halfway anymore
- When a script asks for your OK, you see the whole script first
- Typed text and contacts stay out of logs
- Bunch of small stuff, [full list here](https://github.com/sAnct1x/Arelis/compare/v0.3.1...v0.3.2)

Installer still isn't signed, so Windows will warn you. Hit More info, then Run anyway.
