This is a large release: hundreds of files changed since 0.2.9. The
list below is not complete. It covers the changes you are most likely
to notice, and the ones that need a warning.

---

## Fixed

- Unit and math questions, text extraction from Word (.docx) files, and
  "open this page and tell me what it says" were sent to the wrong
  tool. They now go to the tool meant for them.
- Converting a file she just wrote to another format works.
- Charts accept `x` and `y` names, and the "ran out of steps" message
  says which tool failed.
- A long research task that is still reading pages is wrapped up from
  what she has found instead of being cut off.
- A reservation search for a party of 0 now means one guest, not two.

## New

- Simplified Chinese. Settings, Language switches the window text, her
  replies and the conversation voice (she hears Mandarin and speaks
  it). Window text that has no translation yet stays in English.
- A `run_task` tool that runs a program the project already named
  (tests, `package.json` scripts, or entries in `arelis-tasks.json`).
  It is not a shell, and it asks every time, including by voice.
- Confirm cards now preview what is about to happen: a workspace write
  shows what will change, a program run says what it will start, and
  lines that look like deletes are quoted.
- Adding an agenda block on top of another event warns you about the
  overlap. A reply drafted from the inbox goes to the same send card,
  so there is one yes between the draft and the send.
- Research turns follow search, then open one of the hits, then search
  again. She will not fetch an address that was not in the results or
  in your ask.
- Documents and mail she writes use the Zen Kaku Gothic New and Space
  Mono typefaces. Window buttons ease in when the pointer is near them.
- New dark Night color option (View menu). The default look is
  unchanged.

## Privacy and safety

- Your city, postal code and coordinates are no longer added to every
  prompt, and the logs hide them by default. She looks them up only
  when a question needs them.
- She refuses file paths that point at network shares or Windows
  device paths, so a bad web page cannot make Windows start a network
  login.
- In a chat turn, sending mail or a text, and deleting, pauses for your
  OK whatever the confirm settings say. The Filament (testing) look is
  exempt for mail and texts.
- From this version on, before an in-app upgrade she copies your memory
  and a few settings files (rooms, jobs, contacts, profile, lessons,
  local settings) into a folder named `pre-<version>` under `backups`,
  and keeps the newest two. Never your passwords or tokens. If the copy
  fails she says so before the installer starts. Upgrading from 0.2.9
  to 0.3.0 itself is not covered, because the copy is made by the
  version you are leaving: copy your data folder by hand first if you
  want a backup of that step. A setup file you run by hand never makes
  a backup. See [backups.md](../backups.md).
- When a site shows a "prove you are human" wall, `scrape` and
  `web_fetch` stop and offer to open the page in her Chrome for you.
  If you are away from Arelis for two minutes while she waits on you,
  a Windows notification should say so; I have not yet seen that
  notification on a real Windows PC. Nothing leaves your PC, and she
  does not try to solve the wall. A short page that only talks about
  captchas can be mistaken for a wall.
- Her Chrome keeps your sign-ins between runs (a new setting,
  `tools.browser.fresh_profile: true` in your local settings file,
  starts her window empty every run). This leaves a persistent,
  possibly signed-in profile on disk, in her own Chrome profile folder.
- A switch to turn off the once-a-day update check: put
  `updates.check: false` in your local settings file
  (`config.local.yaml` in the data folder). Off means the daily check
  sends no request to GitHub.
- Setup problems on first run now say what happened in plain words
  (no internet, disk full, installer did not finish, engine did not
  start) instead of a raw error string. The raw text is still in the
  log.
- Earth: removed the optional camera-search layer. Cameras still come
  from public operator catalogs, OpenStreetMap and your own cameras;
  cameras found by searching open ports stay off. If you had saved a
  key for it, it is simply ignored.
- SECURITY.md says I aim to reply to security reports within 7 days.

## Still true

- The installer is not signed, so Windows will warn you the first
  time (More info, then Run anyway). Check the hash against the
  `.sha256` file.
- Ollama and the voice files download on first run, not inside the
  installer.
- Earth and the 3D views still need a source checkout.
- An experimental setting for letting the model pick its own tools
  exists but is off, and I am not working on it.
