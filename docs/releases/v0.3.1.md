# Arelis v0.3.1

What you get if you install this one. Checkout notes stay in
[whats-new.md](../whats-new.md).

A fixes-only release since 0.3.0. Short list of what you are most
likely to notice.

---

## Fixed

- Before an in-app upgrade, the safety copy of your records now sits
  next to the data folder, not inside it, so a wipe uninstall keeps
  those copies. If the copy fails, the update does not start.
- Choosing to remove your data when you uninstall now really removes
  it. Your backups are kept. A data folder you chose yourself is left
  alone.
- Status lines now say, in plain words, what is ready, off, or not
  set up yet.
- In Apps and Features the name is plain Arelis. The version still
  shows in its own column.
- Short real pages that mention captchas are read again. A huge
  reminder delay turns the reminder off instead of crashing, and the
  reminder wording no longer repeats itself.
- Everyday math and unit questions get a real answer again. Dates,
  book titles, and 24/7 are not treated as arithmetic.
- A missing calendar no longer prints a file path. The booking card
  shows a plain day and time, and names the site that opens.
- A reply that is only Done after a page read is rewritten into a
  real answer. A real sentence that starts with Done still ships.
- The workspace status line hides the saved place when location
  hiding is on.
- More entry points refuse network and device paths before touching
  the disk. Pay, Checkout, and Windows permission cards follow their
  switches the way the docs say.

## Still true

- The installer is not signed, so Windows will warn you the first
  time (More info, then Run anyway). Check the hash against the
  `.sha256` file.
- Ollama and the voice files download on first run, not inside the
  installer.
- Earth and the 3D views still need a source checkout.
