# Arelis v0.2.3 — not tagged yet

Draft. GitHub latest is still 0.2.2.

First open can name a model. Rooms come back. Mail, SMS, and calendar
stay off until connected.

A new copy looks at this PC, recommends one chat model, explains why, and
pulls it. Confirm it, or pick Gemma / DeepSeek. One model at a time: both
composer chips are the same tag.

An upgrade from 0.2.2 that never pinned a tag in `config.local.yaml` is
asked once. A copy that already pinned a tag is not.

---

## First open names a model

After the folder question (still the only permission):

1. Looks at graphics memory, RAM, and free disk. Stays on this machine.
2. Recommends the largest Qwen 3.5 that fits, with a why you can read.
3. **Use this model**, or **Choose a different one**.
4. If Ollama is missing, downloads the official Windows engine (~1.4 GB)
   into `%LOCALAPPDATA%\Arelis-runtime`, then the chosen tag plus
   `nomic-embed-text`. Already-pulled tags are skipped.
5. A short how-to. Mail, phone, and calendar still wait in Settings.

Escape on the recommendation confirms the model on screen. Escape during
a pull is ignored.

Auto-pick is always Qwen, sized to the card (`4b` / `9b` / `27b` /
`35b`). No dedicated card stays on 4B or 9B. Gemma is listable, never
auto-picked (12B sat thinking for minutes on a two-tool turn here).
DeepSeek is opt-in reasoning.

Shipped last-resort in `default.yaml` is `qwen3.5:9b` for both chips.
Vision stays `qwen2.5vl:3b`, pulled the first time she looks at a
picture.

## Allow / deny

Risky things still pause.

- The headline is what she wants: **text wife**, **write note.txt**,
  **open youtube**.
- Two lowercase buttons: **allow** and **deny**. Deny is this step only.
  Esc is deny. Enter is allow.
- Typed **no** / **deny** / **don't** denies. Typed **yes** / **go ahead**
  allows. An empty Enter still allows.
- Conversation mode keeps the mic on while the card is up.
- A drive you already typed or said is the grant. Mail and texts still
  show the exact message. **Settings → Allow** is the list.

## Also in this sitting

- The last room you entered comes back on launch.
- Mail, SMS, and calendar tools are not offered until connected.
- A clock ask does not load the full tool list.
- Documents: PDF / Word / Excel / markdown as real files.

Search is still one tool, no keys: DuckDuckGo HTML, then Lite, then
Wikipedia (skipped for news from today or this week). Inbound SMS
flashes the taskbar if you are in another window.

## Not in this patch

- Code signing (SmartScreen will still warn)
- Bundling Ollama inside the setup `.exe` (fetched on first open if
  missing)
- Llama / Phi / gpt-oss in the picker
- Mail / phone / calendar inside the first-run window
