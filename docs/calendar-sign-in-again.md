# When Google asks you to sign in again

Google can drop the saved login. That happens if you close the
sign-in window, or if a test login ages out (about a week). Arelis
forgets that dead login so it does not keep failing in the background.

The next time you sync or add something on the calendar tile, the
sign-in window opens again. Closing that window does not make it
return on its own. Events you already made stay on the local tile
until Google is connected.

Press **sign in** on the calendar tile (Ctrl+7) if you want to start
that now. There is no terminal command for this.

First-time setup is in [calendar-oauth.md](calendar-oauth.md).
