# First run

The first time you open Arelis, she asks two things.

## The folder

She asks which folder she may use. She can only read and write inside that
folder. You can add more folders later in Settings.

## The chat model

She looks at this PC (graphics memory, system memory, and free disk), then
recommends a chat model and downloads it. Nothing is sent to a paid chat
service. The file stays on this machine.

There are two sizes of the same model:

- About 22.1 GB. This is the usual choice on a 12 GB graphics card.
- About 16.6 GB. This is the smaller file when memory is tight, or when she
  cannot read how much graphics memory this PC has.

She also fetches a smaller picture file next to it, so she can look at images
you send.

You need enough free space on the same drive as her models folder, a bit more
than the download size.

## If the connection drops

The unfinished file stays on disk. Open Arelis again and continue. She picks
up from where it stopped, and does not start the download over.

If you close the window before the download finishes, the next launch asks
again. The unfinished file is still there.

Once the file is on this PC, she does not ask again.
