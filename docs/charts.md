# Charts

When you ask for a chart, Arelis draws it right away. There is no Allow card first.

The plot tool only writes a new PNG (and an SVG and PDF for poster, paper, or slide looks) inside the Arelis workspace. With a project folder open, it lands in that project's `plots/` folder. Otherwise it lands under `outputs/plots/`. It never overwrites your own files and never sends anything.

Saved jobs that run while you are away still cannot draw charts.
