# Describing a picture by its name

Ask Arelis to "describe m31.png" and it finds the picture even when it sits in a
subfolder of your workspace, such as `work/m31.png`. You don't need to type the
folder.

- The name must match one file. If two folders each have an `m31.png`, Arelis
  says it can't find it. Give the folder too: "describe work/m31.png".
- This works for png, jpg, jpeg, webp and gif files.
- Pictures you paste or that Arelis made are found the same way as before.
