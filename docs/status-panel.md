# Status panel

Click **house ▾** in the status row under the title bar. The short
lines there tell you what is ready. Here is what the new ones mean.

**This chat model isn't on the server yet**
Chat cannot start because the model she wants is not on the model
server. She looks for the model file name, or a short name for that
same file. Start the model server with that model, then wait a few
seconds. When the line turns green, you can talk.

**Memory search is ready.**
She can look through her memory. Nothing to do.

**Memory search is off.**
She cannot search memory right now. That is not a problem. Chat
still works. Start the memory helper if you want search, or leave
it off.

**Pictures start on demand.**
She can draw when you ask. The picture program is not running yet,
and that is fine. Ask for a picture and it will start.
